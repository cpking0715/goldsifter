# AI 模型配置指南

千淘支持任何 **OpenAI 兼容**的模型服务。推荐从内置供应商中选择（设置 → AI 模型），
只需粘贴 API Key、选择模型即可；也支持自定义（OneAPI / NewAPI / 本地 Ollama 等）。

## 推荐：智谱 AI（免费看图方案）

千淘的核心能力是"看图识货"（判断成色/真伪），需要**支持图片输入的 Vision 模型**。
综合免费、国内直连、多模态三点，推荐智谱：

1. 打开 [智谱开放平台](https://open.bigmodel.cn) 注册（手机号即可）
2. 进入 [API Keys 页面](https://open.bigmodel.cn/usercenter/apikeys) → 创建 API Key → 复制
3. 千淘 → 设置 → AI 模型：
   - 供应商选 **智谱 AI**
   - 粘贴 API Key
   - 模型选 **glm-4v-flash**（`FREE` 角标，长期免费，支持看图）
   - 长文本模型选 **glm-4-flash**（免费；生成分析标准更快更稳）
4. 点「测试连接」→ 通过后「保存」

> 费用参考：glm-4v-flash / glm-4-flash 为官方免费模型（以官网当时政策为准）。

## 关于「长文本模型」

千淘有两类 AI 调用：

- **商品判定**：输出短 JSON，用主模型（建议 Vision 模型）
- **分析标准生成**：一次输出数千字，部分视觉模型（如 glm-4v-flash）的
  `max_tokens` 上限只有 1024，会被截断——因此可单独指定一个文本模型
  （如 glm-4-flash）。系统对超限会自动降级重试，但配置文本模型效果最佳。
  不配置则跟随主模型。

## 自定义供应商示例（本地 Ollama）

1. 供应商选「自定义」
2. Base URL：`http://127.0.0.1:11434/v1`
3. 模型名：你的模型 tag（如 `qwen2.5vl:7b`）
4. API Key：任意非空（Ollama 不校验）

## 常见问题

- **测试连接失败 401**：Key 错误或该 Key 无权限（如智谱 Coding Plan 的 Key 不能调 API，需在开放平台单独创建）
- **429 / 1210 max_tokens 非法**：所选模型输出上限低，系统会自动降级；建议配置长文本模型
- **建任务时"AI 任务生成失败"**：多为模型输出上限截断，切换文本模型后重试
- **不想用 AI**：任务可建「关键词判断」模式，完全离线；或在 .env 设 `SKIP_AI_ANALYSIS=true`
